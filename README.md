## 📖 About

**Pure Python Projects** is a collection of classic beginner Python mini-games and utilities, built while first learning the language. Every project runs on pure Python — no `pip install`, no third-party libraries. Just the standard library and core programming concepts.

These projects cover the fundamentals: string manipulation, randomness, loops, conditionals, functions, and basic I/O — all through games that are actually fun to play.

---

## 🗂️ Projects

### 🔐 Caesar Cipher
Encrypt and decrypt messages using the classic Caesar substitution cipher. Shift each letter in a message by a chosen number of positions.

```
Input:  "Hello World", shift = 3
Output: "Khoor Zruog"
```

---

### 🪢 Hangman
A classic word-guessing game. The player guesses letters one at a time to reveal the hidden word before running out of lives.

- Random word selection
- ASCII hangman art that updates with each wrong guess
- Letter tracking (already-guessed letters displayed)

---

### 🦸 Marvel Hangman
Same gameplay as Hangman, but the word bank is exclusively Marvel superheroes and characters.

```
_ _ _ _ _ _ _ _ _ (9 letters) → SPIDERMAN
```

---

### 🔑 Password Generator
Generate a random password of configurable length from a chosen character pool (letters, digits, symbols).

- Fully customisable character sets
- Random selection using Python's `random` module

---

### ✊ Rock Paper Scissors
Play Rock, Paper, Scissors against the computer.

- Computer makes a random choice each round
- Win/loss/draw result announced
- Play again loop

## 🚀 Getting Started

```bash
git clone https://github.com/Manan-2007/Pure-Python-Projects.git
cd Pure-Python-Projects

# Run any project
python caesar_cipher.py
python hangman.py
python marvel_hangman.py
python password_generator.py
python rock_paper_scissors.py
```

> **Requires:** Python 3.x — no additional installs needed.
